El problema

Una regla de alerta es un programa

  • En los Andes colombianos, las lluvias intensas detonan deslizamientos.
  • La Ley 1523 de 2012 define la alerta como un estado que se declara a partir del monitoreo.
  • Leer un sensor, evaluar una condición, alertar: ALERTA valida esas reglas antes de usarlas.

Fase 1 · Formalismo léxico

Del carácter al token

Σ = P L U E N A
114símbolos en Σ
16clases de símbolos

P: ASCII imprimible · L: minúsculas · U: mayúsculas · E y N: espacios y saltos · A: tildes.

Un carácter fuera de Σ es un error léxico.

Fase 2 · Estructura sintáctica

G0 es ambigua

<exp> ::= <exp> "o" <exp> | <exp> OPSUMA <exp> | <exp> OPMUL <exp> | … | NUM | ID

Una gramática es ambigua si alguna cadena tiene dos o más árboles de derivación. 2 + 3 * 4 da 14 o 20.

Fase 2 · De G0 a G

Tres transformaciones

1

Precedencia

Un no terminal por nivel, como E, T y F:

<exp> o
<conj> y
<rel> == < >=…
<suma> + -  (E)
<prod> * /  (T)
<factor>     (F)

2

Recursividad izquierda

A → Aα | β

↓

A → βA′   A′ → αA′ | ε

Lema 1. Ambas generan βα*: el lenguaje no cambia.

3

Factorización

A → γδ₁ | γδ₂

↓

A → γA′   A′ → δ₁ | δ₂

Lema 2. Distributividad. Se aplicó a si … sino y a <rel>.

Fase 2 · Gramática final

G es LL(1), luego no es ambigua

17no terminales
27terminales
34producciones

Conflictos LL(1): 27 → 0. Las alternativas de cada no terminal tienen conjuntos de predicción disjuntos.

<suma'> → OPSUMA <prod> <suma'>  { + - }
<suma'> → ε  { ) ; OPREL y o … }

2 + 3 * 4: derivación por la izquierda y por la derecha, 17 pasos cada una, un solo árbol → 14.

# <suma'> ::= OPSUMA <prod> <suma'> | ε
def suma_prima(self):
    if self.tipo() != "OPSUMA":
        return epsilon("<suma'>")
    return Nodo("<suma'>", [self.consumir("OPSUMA"),
                         self.prod(), self.suma_prima()])
